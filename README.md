
# Mini Portafolio Personal

## Descripción

Este proyecto consiste en un portafolio web personal desarrollado
con React, TypeScript y Vite, donde presento información sobre mí,
mis habilidades, herramientas y proyectos académicos.

El diseño está basado en el wireframe proporcionado, utilizando
una interfaz sencilla, organizada y adaptable a distintos tamaños
de pantalla.

## Instalación y ejecución

Para ejecutar el proyecto de manera local, se necesita tener
Node.js y npm instalados.

Instalar las dependencias:

    npm install

Iniciar el servidor de desarrollo:

    npm run dev

Abrir en el navegador:

    http://localhost:5173

## Rutas del proyecto

| Ruta | Descripción |
| --- | --- |
| / | Página de inicio |
| /sobre-mi | Información personal y académica |
| /habilidades | Habilidades y herramientas |
| /proyectos | Proyectos académicos |
| /contacto | Formulario de contacto |
| * | Página no encontrada |

## Componentes principales

- Header: encabezado y menú de navegación.
- Footer: pie de página.
- Layout: estructura general de las páginas.
- TarjetaHabilidad: muestra una habilidad y su nivel.
- TarjetaProyecto: presenta la información de cada proyecto.
- FormularioContacto: formulario con validación de campos.

## Funcionalidades

- Navegación entre páginas mediante React Router.
- Componentes reutilizables.
- Uso de props e interfaces de TypeScript.
- Renderizado de listas mediante map().
- Barras de progreso para las habilidades.
- Tarjetas de proyectos académicos.
- Formulario de contacto con validación.
- Diseño responsive mediante CSS.
- Página para rutas no encontradas.
